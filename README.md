# writing.sungd.uk

> 읽은 것들을, 생각을, 만들면서 알게 된 것을 글로 씁니다.

개인 블로그입니다. 책을 읽고, 세상을 겪고, 머릿속을 정리한 것을 글로 남깁니다. 글쓰기는 생각의 근육을 키우는 연습이자, 나를 돌아보는 시간입니다.
