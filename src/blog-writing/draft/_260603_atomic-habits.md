- 습관 순환
  - 그림
    - 신호 → 열망 → 반응 → 보상
    - 문제 국면 / 해결 국면

|      | 좋은 습관 형성 | 나쁜 습관 제거  |
| ---- | -------------- | --------------- |
| 신호 | 분명하게       | 보이지 않게     |
| 열망 | 매력적으로     | 매력적이지 않게 |
| 반응 | 하기 쉽게      | 하기 어렵게     |
| 보상 | 만족스럽게     | 불만족스럽게    |

- 습관의 변화는 인식에서 시작한다.

- 실행 의도 공식: 나는 \[언제\]\[어디서\]\[어떤 행동\]을 할 것이다.
- 습관 쌓기 공식: \[현재 습관\]을 하고 나서 \[새로운 습관\]을 할 것이다.

- B = f(P, E)
  - 자주 인지할 수 있는 환경 만들기
- 공간/맥락을 분리하라

- 나쁜 습관을 없애려면 보이지 않게.
  - 자제력은: 요혹 ↑ 환경 X

- 유혹 묶기: 해야하는 일 - 원하는 일
  - - 습관 쌓기

- 세 집단 모방
  - 가까운
  - 다수
  - 유력자
- 그 문화에서 더 잘 형성

- 나쁜 습관은 예측(ㄴ신호)를 바꾸는 방법으로 안 됐을때 이득 생각
- 습관을 자신이 즐기는 것과 연관
  - get to ✓ 해내다
  - have to X 해야한다

- 환경이 중요하다.

- 2분 규칙. 최대화 전에 표준화.

- 이행 장치 만들기. Commitment Device
  - (세이렌) 미리!

- '좋은 습관은 현재에 비용을, 나쁜 습관은 미래에'
  - 뇌리?에도 분에 보이는 보상을

- 습관 추척: 1) 시각적 신호 → 2) 내적 동기 → 3) 만족감
  - \[현재 습관\] 후 \[습관 추적\]
  - (한 번은 괜찮지만) 두번은 거르지마라 ★

- 습관을 계약으로 \[✓\]

- 나에게 맞는 습관도 있다. 찾아보자.

- 골디락스 법칙[^1]
  - 그림
    - 지루 - (존) - 실패
  - 아마추어 vs. 전문가
    - 지루함을 견디는게 관건
    - 되는대로 vs. 일정대로

- 습관 + 의도된 연습[^2] = 숙련
  - 습관에 익숙해지면 오히려 정체
  - ⇒ 반추 & 숙고. '연간 리뷰'
  - 정체성을 작고 유연하게.[^3]

- 삼단 논법.
  - 어느 순간 무게가.
